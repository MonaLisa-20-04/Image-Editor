A simple, interactive, browser-based image editor built using **HTML, CSS, and Vanilla JavaScript**. It allows users to upload an image, adjust its appearance using real-time filter sliders, and download the edited result.

## ✨ Features

- **Image Upload:** Upload an image from your local device.
- **Live Preview:** View image modifications directly on an HTML Canvas.
- **Adjustable Filters:** Customize image appearance using interactive sliders.
- **Multiple Image Effects:** Includes controls for:
  - Brightness
  - Contrast
  - Saturation
  - Hue Rotation
  - Blur
  - Grayscale
  - Sepia
  - Opacity
  - Invert
- **Reset:** Restore the image to its original appearance.
- **Download:** Save the edited image to your device.
- **Interactive Interface:** Simple and intuitive controls for image customization.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash

```

### 2. Navigate to the Project Directory

```bash
cd Image-Editor
```

### 3. Run the Application

Open `index.html` in your preferred web browser.

You can also use the Live Server extension in Visual Studio Code for a convenient development experience.

## 💡 How It Works

1. Upload an image using the image upload option.
2. The selected image is rendered on an HTML Canvas.
3. Adjust the available filter sliders to modify the image.
4. Changes are reflected in the image preview.
5. Use the Reset option to restore the original image.
6. Download the final edited image.

The application uses JavaScript to handle user interactions, manage filter values, and update the image preview.
